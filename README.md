# 📱 基本情報クイズアプリ
 
> 基本情報技術者試験の学習をサポートするiOSクイズアプリ  
> 5人チームで開発 | SwiftUI製
 
---
 
## 📖 概要
 
基本情報技術者試験の合格を目指すために制作した、iOS向けの学習支援クイズアプリです。  
選択式・記述式の2種類の出題形式に対応しており、カテゴリ別に効率よく学習できます。  
間違えた問題や学習履歴を記録する機能も搭載しています。
 
---
 
## ✨ 機能一覧
 
### 🧠 クイズ機能
- **選択式クイズ** : 4択から正解を選ぶ形式
- **記述式クイズ** : 自分でキーワードを入力して回答する形式
### 📂 カテゴリ学習
- 分野ごとにカテゴリを分類し、苦手な分野を集中して学習可能
### 📝 学習記録
- 学習履歴を自動保存
- 間違えた問題を記録し、苦手問題を繰り返し復習できる
### 🖥 画面構成
 
| 画面名 | 内容 |
|--------|------|
| StartView | スタート画面 |
| QuizView | 選択式クイズ画面 |
| InputQuizView | 記述式クイズ画面 |
| ResultView | 結果表示画面 |

## 🚀 セットアップ
 
```bash
# リポジトリをクローン
git clone https://github.com/Riokkuma/xcodeapp.git
 
# Xcodeで開く
open xcodeapp.xcodeproj
```
 
1. Xcodeでプロジェクトを開く
2. シミュレーターまたは実機を選択
3. `⌘R` でビルド・実行
