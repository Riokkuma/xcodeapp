# 🐻 基本情報クイズアプリ

基本情報技術者試験の合格を目指すための学習クイズアプリです。

---

## 📱 対応環境

- iOS 17.0 以上
- Swift 5.9 / SwiftUI

---

## 🎮 機能一覧

### クイズ機能

#### 選択式クイズ
- 4択形式で問題に答える
- 1問あたり **10秒のタイムアタック**
- 残り時間に応じてタイマーバーの色が変化（緑 → 黄 → 赤）
- 回答後に正解・不正解をその場で表示
- 間違えた選択肢と正解の選択肢をハイライト表示

#### 入力式クイズ（記述式）
- キーボードで答えを直接入力する記述式
- 大文字・小文字は区別しない
- 不正解時に正解をその場で表示

### 復習機能
- 結果画面から **間違えた問題だけもう一度** 解き直せる
- 選択式・入力式それぞれ対応

### 学習履歴（📊）
- 直近7回の正答率をバーグラフで可視化
- 分野別の苦手ランキングを表示
- 全プレイ履歴の一覧（日時・正答率）
- データは **UserDefaults で永続保存**（アプリを閉じても残る）

### 間違いノート（📝）
- 間違えた問題を自動で記録
- カテゴリでフィルタリング可能
- ミス回数が多い問題順に表示
- まとめてリセット可能

### ホーム画面の統計カード
- 🔥 連続学習日数（ストリーク）
- 📊 最新正答率
- 📝 総プレイ数

## 📚 出題分野

| 分野 | 問題例 |
|------|--------|
| ネットワーク | TCP・OSI参照モデル・ARPなど |
| セキュリティ | マルウェア・暗号化方式・証明書など |
| データベース | 主キー・外部キー・SQLなど |
| ハードウェア | キャッシュメモリ・スレッド・耐障害設計など |
| ソフトウェア開発 | 要件定義・スクラム・UMLなど |
| プロジェクト管理 | ステークホルダ・問題管理など |
| 経営戦略 | SWOT分析・システム化計画など |

## 🗂 ファイル構成

```
Quiz/
├── QuizApp.swift         # アプリのエントリーポイント
├── Models.swift          # データ構造・Enumの定義
├── AppColors.swift       # 色・ボタンスタイルの定義
├── DataManager.swift     # 学習履歴・間違いノートの永続保存
├── ContentView.swift     # 画面切り替えの司令塔
├── StartView.swift       # ホーム画面
├── QuizView.swift        # 選択式クイズ画面
├── InputQuizView.swift   # 入力式クイズ画面
├── ResultView.swift      # 結果画面
├── HistoryView.swift     # 学習履歴画面
└── WrongNoteView.swift   # 間違いノート画面
```

---

## 🖼 画面遷移

```
StartView（ホーム）
├── QuizView（選択式クイズ）  → ResultView（結果）
├── InputQuizView（入力式）   → ResultView（結果）
├── HistoryView（学習履歴）
└── WrongNoteView（間違いノート）
```

---

## 🛠 使用技術

- **SwiftUI** - UI全体
- **UserDefaults** - 学習履歴・間違いノートの永続保存
- **Timer** - タイムアタック機能
- **ObservableObject / EnvironmentObject** - DataManagerの全画面共有
